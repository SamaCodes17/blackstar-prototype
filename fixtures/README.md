# Dataset provenance

`vcdb-aggregate.json` is a modified aggregate of the VERIS Community Database by the Verizon RISK Team and contributors, revision `230cf22b56a481dd1a994b21e4d94c59e2bccea9`.

Source: https://github.com/vz-risk/VCDB/tree/230cf22b56a481dd1a994b21e4d94c59e2bccea9

This data license does not designate a license for the app's independently written code. Preserve attribution and share-alike terms when redistributing modified data.

BlackStar modifications: validated records only, deduplication by incident ID, exclude known preferential `phidbr`/`priority` records, require a confirmed incident and external actor, aggregate disjoint ransomware / credential / other categories, action types and asset varieties by two-digit NAICS sector. Victim names, free text, domains, references and incident-level records are omitted. Counts are not anonymization claims about upstream records.

10,047 input files; 4,623 retained records. Exclusions: 1,900 known preferential selections, 3,417 without external actors, 63 unconfirmed and 44 missing/duplicate IDs. Reporting and selection bias remain. Counts are not population attack rates. The dataset has no denominator of unbreached companies.

Rebuild: download the pinned revision ZIP from `https://codeload.github.com/vz-risk/VCDB/zip/230cf22b56a481dd1a994b21e4d94c59e2bccea9`, then run `python scripts/import_vcdb.py artifacts/vcdb.zip`. The artifact records its SHA-256 and revision. Python is only an offline data-preparation tool; deployed service needs Node only.

Demo organizations are independently generated by `server/demo.ts` using reserved `.example` domains and `192.0.2.0/24` addresses. Company names are fictional, and do not assert facts about any similarly named real entity. Employee counts, assets, records, costs, dependencies and baseline probabilities are synthetic/assumed. This deterministic generator replaces a Mockaroo dependency and avoids accidentally generating a live target.

`ct-srmist.json` is retained for legacy tests/history only. It is not a public demo organization or fetched on startup. The retired SQLite data is never imported into the new runtime.
